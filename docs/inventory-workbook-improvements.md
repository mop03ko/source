# AOM агуулахын сайжруулалт — 2026-09-18

Эх сурвалж: `AOM Inventory-2026.09.17.xlsx`. Бодит санг өөрчлөөгүй; импортын туршилт түр локал санд хийгдэнэ.

## Файлаас тогтоосон бүтэц

- `Balance`: код, брэнд/нийлүүлэгч, нэр, багтаамж, өнгө, IMEI, агуулах, эхний/эцсийн тоо ба өртөг, орлого/зарлага, борлуулах үнэ.
- `Purchase`: захиалга, хүлээн авалт/буцаалт, нэмэлт бэлтгэлийн зардал, төлбөрийн төлөв.
- `Sales`: билл, харилцагч, платформ, салбар, өртөг, шимтгэл, татвар, ашиг, төлбөрийн данс.
- `Parameter`: 24 платформын шимтгэл/дансны анхны тохиргоо. Эдгээр нь файлын утгууд бөгөөд системээс засаж болно.
- `vendor`: нийлүүлэгчийн мэдээлэл. Энэ хувилбарт барааны нийлүүлэгчийг тусдаа талбараар хадгална; гэрээ, хаягийн бүрэн CRM нэмээгүй.

## Импортын шалгалт

Balance-ийн код/нэртэй 3,114 мөр болон код дутуу нэг мөрийг шалгав. Хэвийн 3,096 мөрд 429 үлдэгдэлтэй бараа, нийт 1,524 ширхэг байна. Таван байршил: Арын агуулах, Урд агуулах, Заал, ТҮМЭН МОЛЛ, GOTO.

19 мөрийг зөрчилтэй гэж тусгаарлана: код/нэр/агуулах дутуу 1, сөрөг өртөгтэй 2, тэг үлдэгдэлтэй боловч өртөгтэй 9, захын зайг арилгахад код давхардсан 7. Импортын цонх мөрийн дугаар, шалтгааныг харуулж, алгасах зөвшөөрөл болон серверийн урьдчилсан шалгалт шаарддаг. Одоо байгаа кодыг дарж бичихгүй. Давтан ижил хүсэлт үлдэгдэл дахин нэмэхгүй.

Файлын нэр 09-17 боловч Balance-ийн Q1/R1 нь 09-18/09-19. Импортын огноог файлын дотоод эцсийн хязгаарын өмнөх минут буюу 2026-09-18 23:59 УБ гэж санал болгож, хэрэглэгч засах боломжтой. Формулын хадгалсан үр дүнг уншдаг; формулыг ажиллуулахгүй. Эцсийн тоо/өртгийн утга дутуу мөрийг зөрчил гэж үзнэ.

`.xlsx` файлыг браузерт уншина. Бүтэн workbook серверт илгээгдэхгүй; сонгосон Balance мөрүүдийг л илгээнэ. Purchase/Sales түүхийг эхний үлдэгдэлтэй давхар импортлохгүй. Анхны файлд өөрчлөлт оруулахгүй.

## Өөрчлөлтүүд

- Агуулах, брэнд, үлдэгдэл, код/IMEI/нэрээр шүүх; доод үлдэгдлийн сануулга; бараа засах; байршил бүрийн тоо ба өртөг.
- Худалдан авалт: захиалсан үед үлдэгдэл нэмэгдэхгүй; хүлээн авмагц нэмэгдэнэ. Нийт өртөг = нэгжийн үнэ × тоо + нийт нэмэлт зардал. Хэсэгчилсэн болон бүтэн нийлүүлэгчийн буцаалт.
- Агуулах хоорондын шилжүүлэг: гарах/орох хөдөлгөөн хамт хадгалагдаж, нийт тоо болон өртөг хадгалагдана.
- Борлуулалт: агуулахын тухайн үеийн жигнэсэн дундаж өртөг, платформын шимтгэл, хэрэглэгчийн оруулсан татвар, билл, данс, баримтын төлөв. Ашиг = борлуулалт − өртөг − шимтгэл − татвар. Татварын хувь автоматаар таамаглахгүй.
- Огнооны тайлан: эхний үлдэгдэл + орлого − зарлага = эцсийн үлдэгдэл; тоо болон өртгийн аль алинаар. УБ өдрийн хил ашиглана. CSV экспорт шүүлтүүрийг дагаж, том тайланг чимээгүй таслахгүй.
- Мөнгөн хөдөлгөөнийг бүхэл зууны нэгжээр хадгалж, бүрэн зарлагадахад үлдэгдэл өртгийг бүрэн тэглэнэ. Буцаалт/шилжүүлэг тухайн үеийн дундаж өртгөөр гарна. Өнгөрсөн огноотой бичлэг өмнөх борлуулалтын өртгийг дахин тооцохгүй.
- Бүх өөрчлөлт write transaction-д хийгдэнэ. Хуучин хувилбартай хүсэлт, давтан дуусгалт, зэрэг борлуулалт өгөгдөл эвдэхгүй. Тооллого эхэлснээс хойш тухайн агуулахын хөдөлгөөн өөрчлөгдвөл шинээр тоолох шаардлагатай.
- Формын хадгалаагүй өөрчлөлтийг хамгаална. Тооллогын бүх мөрийг бөглөөгүй үед дуусгахгүй; хаагдсан тооллогыг засахгүй.

## Шилжилт ба шалгалт

Шинэ migration: `drizzle/0021_kind_jackal.sql`. Шинэ кодыг ажиллуулахын өмнө тухайн орчинд `npm run db:migrate` ажиллуулна. Энэ ажлаар production migration/deploy/push хийгээгүй.

Migration хуучин мөрүүдийг устгахгүй. Өртөггүй хуучин хөдөлгөөнийг бүртгэлтэй худалдан авалтын дундаж өртгөөр нөхөн тооцож, тайлан дээр ойролцоо дүн гэж тэмдэглэнэ. Хуучин дуусаагүй тооллогыг хөдөлгөөний шинэ хамгаалалттайгаар дахин үүсгэнэ.

Шалгах командууд:

```text
npm run lint
npm run typecheck
npm test
npm run build
node scripts/inventory-audit.mjs <xlsx-файлын-зам>
```

`inventory-workflows.test.cjs` нь зэрэг хүсэлт, мөнгөний нарийвчлал, шилжүүлэг, буцаалт, импортын бүхэл хадгалалт, тооллогын хамгаалалтыг шалгана. Браузерын скрипт тусгаарласан санд компьютер/утасны харагдац, барааны дэлгэрэнгүйгээс зарлага нээх, тайлан болон бодит workbook импортлох урсгалыг шалгана. Evidence болон локал хөрвүүлсэн CSV нь git-д орохгүй `artifacts/` дотор хадгалагдана.
