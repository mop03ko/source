# AntMall CRM — UX/UI засварын тайлан

2026-09-18 · Локал эх код, production build, тусгаарласан туршилтын өгөгдөл.

[Өмнөх аудитын](../ux-audit-2026-09-18/README.md) 22 асуудалд засвар хэрэгжүүлэв. Нэмэлтээр браузерын зөв POST хүсэлтийг 403 болгож байсан origin шалгалтыг засав. Production серверт байршуулалт хийгээгүй.

Сэргээсэн хүсэлт “Мэдээлэл шалгах” төлөвт орж, дуудлага автоматаар товлохгүй. Хуучин үйлдлийн түүх, утасны хориг хадгалагдана. Хариуцагч, төлөв, товыг шалгаж үргэлжлүүлнэ.

Чатын ноорог нь нээлттэй цонхны санах ойд хадгалагдана. Browser хаахад байнгын хадгалалт хийхгүй; хадгалаагүй өөрчлөлтийн анхааруулга үйлчилнэ. Native date/time picker-ийн дотоод хэл браузерын тохиргооноос хамаарна; харагдах огноо ба цагийн бүсийн тайлбар тогтвортой.

## Нэмэлт алдаа: зөв хүсэлтийн 403

Браузер `http://127.0.0.1:34672`-оос POST илгээхэд Next.js route доторх URL `http://localhost:34672` байсан. Өмнөх шууд харьцуулалт бүх ийм хадгалалтыг буруу хориглож байв.

Нийтлэг `isSameOrigin` шалгалт нь browser-ийн очих `Host` болон protocol-ийг ашиглана. Хоосон/`null` origin, өөр сайт, буруу host-ыг зөвшөөрөхгүй; `x-forwarded-host`-оор шалгалтыг тойрох боломж өгөөгүй. CRM, IT, маркетинг, SMS, тохиргоо, профайл, чат, мэдэгдэл, Sheets-ийн POST урсгалд хэрэглэв. Same-site амжилт болон cross-site татгалзалтыг production HTTP тестээр батлав.

## Баталгаажуулалт

- `npm.cmd run lint` — алдаа, warning 0.
- `npm.cmd run typecheck`, `npm.cmd run build` — амжилттай.
- `npm.cmd test` — үндсэн 7 багц болон календарийн өдрийн хуудсалалт, scope, restore эрх/хувилбар/түүх/хоригийн нэмэлт шалгалтууд амжилттай.
- `npm.cmd run test:production` — signed session, зөв POST, cross-origin болон forwarded-host татгалзалт амжилттай.
- `npm.cmd run test:ux` — Chrome production build дээр 30 screenshot болон үйлдлийн assertions. 320, 360, 390, 768, 1280, 1440 px хүрээнд шалгасан дэлгэцүүд document overflow-гүй; runtime/hydration exception 0.
- Нэг өдрийн бүх 18 хүсэлт нээгдэв. Backend-ийн 55+ ажилтай өдрийг хоёр хуудсаар давхардалгүй авч буйг тестлэв.
- Ноорогтой цонх хаах/таб солихыг цуцлах, SMS retry/explicit save/delete cancel-confirm, чат хоорондын ноорог, URL refresh, сэргээх UI-г туршив.

| Хэмжилт | Өмнө | Дараа |
|---|---:|---:|
| 390 px борлуулалтын document өргөн | 651 px | ≤390 px |
| 390 px тохиргооны document өргөн | 508 px | ≤390 px |
| Үндсэн товчны текстийн contrast | 2.47:1 | 5.85:1 |
| Хүснэгтийн гарчгийн contrast | 2.94:1 | 6.26:1 |
| Туслах текстийн цагаан суурьтай contrast | 2.95:1 | 6.74:1 |
| Dashboard батлах хэсгийн байрлал | ~2883 px | ~369 px |

Өнгөний харьцааг CSS foreground/background-ийн relative luminance-аар тооцсон; эдгээр нь дээрх тодорхой өнгөнүүдийн хэмжилт.
