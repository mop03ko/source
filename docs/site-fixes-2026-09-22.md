# Сайтын аудитын засвар — 2026-09-22

## Хэрэгжүүлсэн

- Маркетинг, IT-ийн сервер болон цэс нэг зөвшөөрөх жагсаалт ашиглана. Хүргэлт, оператор болон бусад зөвшөөрөлгүй role-ийн жагсаалт, дэлгэрэнгүй, бичих үйлдлүүдийг хаасан.
- Хуваарийн lint алдааг засаж, сарын төлөвлөгөөг нээх үед эхлүүлдэг болгосон. Бүртгэхийн өмнө ажилтан тус бүрийн нэмэх / алгасах өдрийн тоог харуулна. Бүртгэлтэй томилгоог хөндөхгүй.
- Sidebar-ийн зайг эхний render-ээс нөөцөлсөн. Том модулиудыг хэрэгцээгээр ачаалж, Skeleton харуулна.
- Графикийн зураасанд хүртээмжийн нэр өгсөн; өнгөт Tag-ийн текстийг тодруулсан; жижиг дэлгэцийн dashboard, агуулахын tab-ыг Select-ээр сольсон.
- Хүснэгтийн дэлгэх баганын гарчиг, далд хэмжилтийн мөрийн focus, гарын товчоор гүйлгэх боломжийг зассан.
- Sheets синкийн өгөгдлийн revision өөрчлөгдсөн үед CRM-ийг шинэчилнэ. Нэр, мөрийн мэдээлэлгүй opaque revision ашиглана. Тусгаарлагдсан role-ууд синк polling хийхгүй.
- Борлуулалт, агуулахад нэрлэж хадгалдаг шүүлтүүр нэмсэн. Энэ төхөөрөмж дээр хэрэглэгч + role тус бүрээр хадгална; огноо автоматаар шилжихгүй.
- Үлдэгдлийн тайлангаас зөвхөн сөрөг үлдэгдэлтэй барааг тайлбартай шүүнэ. Экспорт мөн ижил stock шүүлтүүр ашиглана. Өмнөх багана сонголт, IMEI/баркод, bulk сонголтыг хадгалсан.
- Маркетинг, IT-д хоцорсон, идэвхтэй хариуцагчгүй ажлын шүүлтүүр; Маркетингт батлаагүй төсвийн шүүлтүүр нэмсэн. Үйлдлийн түүхийг Ant Timeline ашиглан харуулна.
- Хүргэлтэд өнөөдөр / хоцорсон / биелээгүй хурдан шүүлтүүр нэмсэн. Биелээгүй, цуцалсан төлөв рүү шилжихэд шалтгаан шаардана.
- Чат дотор серверийн хайлт нэмсэн: Монгол кирилл том/жижиг үсэг үл харгалзана, сүүлийн 50 тохирох зурвасыг харуулна. Группийн гишүүнчлэл, хувийн чатын оролцогчийн хүрээг мөрдөнө.
- Зургийн base64-ийг чатны жагсаалт, polling JSON-д дахин дамжуулахгүй. Зургийг зурвасын эрх шалгадаг тусдаа GET хүсэлтээр ачаална. Хуучин зураг хэвээр ажиллана; DB migration шаардлагагүй.
- Sheets холболтын амжилт ба импортын бүрэн байдлын ялгааг тайлбарласан. Маягтын input үйл явдал дээр native validation method байхгүй үед алдахгүй болгосон.
