# Эрхэд тохирсон Хяналтын самбар

Хяналтын самбар бүх хэрэглэгчийн эхний цэс, анхны хуудас боллоо. Тусдаа Өнөөдрийн ажил цэсийг хассан. Хуучин `?view=today` холбоос, буцах/урагшлах navigation нь `dashboard` руу хэвийн шилжинэ.

| Эрх | Хяналтын самбарын ажил |
| --- | --- |
| Админ, удирдлага | Багийн холбоо барих дараалал, хуваарилалт/хүргэлтийн холбоос, ерөнхий тайлан болон төсөв батлах хэсэг |
| Ахлах | Багийн өнөөдрийн холбоо барих дараалал, хуваарилалт, хүргэлт хянах холбоос |
| Борлуулалтын ажилтан | Өөрт хуваарилсан өнөөдрийн/хоцорсон хүсэлт, өөрийн өнөөдрийн гүйцэтгэл |
| Маркетинг | Өөрт хуваарилсан өнөөдрийн/хоцорсон нээлттэй маркетингийн ажил |
| IT | Өөрт хуваарилсан өнөөдрийн/хоцорсон нээлттэй IT ажил |
| Хүргэлт | Өөрт хуваарилсан өнөөдрийн/хоцорсон хүлээгдэж буй хүргэлт |

Бүх эрх өөрийн өнөөдрийн ажлын хуваарийг харна. Хуваарьгүй үед ил тод тэмдэглэнэ. Маркетинг/IT-д хугацаагүй нээлттэй ажлын тоог тусад нь харуулна. Ажлаас шууд дэлгэрэнгүй рүү орох боломжтой.

Өдрийн хязгаар Улаанбаатар UTC+08. Тусгаарлагдсан эрхийн ажлыг сервер дээр нэвтэрсэн ажилтнаар шүүнэ; owner/role query параметрээр бусдын ажлыг авахгүй. Хүргэлтийн хуучин и-мэйлгүй мөрийг одоогийн журмын адил нэрээр нь тааруулна. Хаагдсан, цуцалсан ажлыг өнөөдрийн дарааллаас хасна. Өдөрт 20 мөрөөр хуудаслана.

Баталгаажуулалт: бүх автомат тест, production build, өөрчилсөн файлуудын ESLint; долоон эрхийн desktop/mobile browser audit (эхний цэс, анхны хуудас, хуучин холбоос, эрхийн агуулга, ажлын дэлгэрэнгүй нээх); CRM bulk selection regression. Нотолгоо `artifacts/dashboard-audit/`.

Өгөгдлийн migration болон production мэдээлэлд өөрчлөлт шаардлагагүй.
