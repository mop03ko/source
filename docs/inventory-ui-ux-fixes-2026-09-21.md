## Шалгалт

- Production build, TypeScript, өөрчилсөн эх файлуудын ESLint.
- Үндсэн `npm test` багц; эцсийн API өөрчлөлтийн дараа inventory products/workflows/counts тестүүд.
- `inventory-audit.mjs`: засахад үлдэгдэл хадгалах, үндсэн/бэлэн үнэ, supplier/category, борлуулалт, график/тайлан, mobile.
- `inventory-products-audit.mjs`: IMEI сонголт, яг сонгосон дугаарын зарлага, sibling stock, parent руу хайлтаа хадгалж буцах, дугаар нэмэх.
- `bulk-selection-audit.mjs`: 50 мөрийн сонголт, холимог checkbox, хуудас/filter reset, Space, хоёр мөрийн CSV, mobile cards.
- `lead-purchase-audit.mjs`: зээлийн худалдан авалт, үндсэн үнэ, агуулахын үлдэгдэл хасалт.
- `inventory-count-workspace-audit.mjs`: 52 мөр, хоёр хуудасны draft, хайлт солих, хоёр хуудасны partial save, дутуу finalize хаалт.
- `inventory-ui-ux-audit.mjs`: 6 таб × 3 өргөн, 8 маягт × 2 өргөн, footer харагдах/form холбоос, keyboard Tabs, URL reload, receive cancel, count review/finalize, empty/error. **43 screenshot; runtime exception, нийт хуудасны өргөний халилтгүй.**

Нотолгоо: [UI засварууд](../artifacts/inventory-ui-ux-fixes-2026-09-21/evidence.json), [тооллого](../artifacts/inventory-count-workspace-audit/evidence.json). Эдгээр локал artifact нь git-д хадгалагддаггүй; скриптээр дахин үүсгэнэ.

Ижил 1440×1000 хэмжилтээр каталогийн эхний өгөгдлийн мөрийн байрлал 1023.64px-аас 592.45px болж дээшилсэн. Mobile screenshot-д нэр, үлдэгдэл, үнэ нэг card-д харагдана. Энэ нь бүрэн WCAG эсвэл жинхэнэ утасны keyboard/screen-reader баталгаажуулалт биш.

## Өгөгдлийн дүрэм

DB migration шаардлагагүй. Бараа нэгтгэх дүрэм, ledger, үнэ/шимтгэлийн бодит тооцоо, role-ын edit эрхийг хадгалсан. Нөхөн таталтын босго нь одоогийн бүртгэлийн түвшинд хэвээр; бүтээгдэхүүн/агуулахын шинэ босгын бодлого руу өгөгдөл шилжүүлээгүй. Өмнөх үетэй харьцуулсан тайлан, агуулахын бүрэн CRUD зэрэг аудитад нэмэлт боломж гэж тэмдэглэсэн зүйлс энэ UI засварын хүрээнд орохгүй.
