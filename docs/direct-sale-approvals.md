# Шууд борлуулалтын баталгаажуулалт

- Борлуулалтын ажилтан (`agent`), оператор (`operator`) `record_sale` илгээхэд `pending` хүсэлт үүснэ. Борлуулалт, агуулахын хөдөлгөөн, сериалын гаралт үүсэхгүй. Өөр ажилтны нэрээр хүсэлт илгээхгүй.
- Ахлах (`manager`), админ (`admin`), удирдлага (`director`) **Агуулах → Борлуулалт → Шууд борлуулалтын хүсэлтүүд** хэсгээс дэлгэрэнгүйг хянаж батална эсвэл шалтгаантай татгалзана. Эдгээр эрхийн шууд борлуулалт бүртгэх одоогийн боломж хэвээр.
- Батлахад идэвхтэй бараа, зарагч, үлдэгдэл, өртгийг дахин шалгана. Хүсэлтийн шийдвэр, борлуулалт, үлдэгдэл, сериалын бүртгэл нэг transaction-д хадгалагдана. Давхар шийдвэр 409 буцаана. Хүсэлт илгээсэн ажилтны борлуулалтын үзүүлэлтэд орно; баталсан ажилтан тусдаа хадгалагдана.
- Хүлээгдэж буй хүсэлт бараа нөөцлөхгүй. Хүсэлтүүд ажилтан/операторт зөвхөн өөрийнх нь хүрээнд харагдана. Борлуулалтын тайланд батлагдсан борлуулалт л орно.
- `0035_direct_sale_approvals.sql` шинэ хүсэлтийн хүснэгт үүсгэнэ; өмнөх борлуулалтуудыг өөрчлөхгүй.
- Шалгалт: `node tests/direct-sale-approvals.test.cjs`, `node tests/direct-sales.test.cjs`, `node scripts/direct-sale-approval-audit.mjs` (сүүлийнх build болон Chrome шаарддаг; зөвхөн тусгаарласан DB ашиглана).
