# Хувийн To-Do

Хяналтын самбарын өдөр тутмын ажлын хэсгийн доор бүх идэвхтэй хэрэглэгч өөрийн To-Do жагсаалтыг ашиглана. Нэмэх, засах, дуусгах, буцааж нээх, баталгаажуулж устгах үйлдэлтэй. 20 мөрөөр хуудаслаж, хийх/дууссан/бүгд шүүлтүүр болон нийт гүйцэтгэл харуулна.

`/api/todos` нь нэвтэрсэн хэрэглэгчийн email-аар сервер дээр хүрээг тогтооно. Админд бусдын хувийн жагсаалтыг харах нэмэлт эрх байхгүй. POST нь same-origin, strict input validation, version conflict хамгаалалттай. UUID-тай нэмэх хүсэлтийг давтан илгээхэд давхар үүсэхгүй. Token болон хэрэглэгчийн owner талбарыг клиентээс хүлээн авахгүй.

Migration: `0036_personal_todos.sql`. Өмнөх ажлын хуваарь, маркетинг, IT болон зээлийн хүсэлтийн ажлуудыг өөрчлөхгүй.

Тест: `node tests/todos.test.cjs`. Browser: build хийсний дараа `node scripts/todo-audit.mjs` — тусгаарласан SQLite ашиглана.
