## Давтаж шалгах баримт, засварын шалгуур

### UX-01 — Шууд борлуулалт 50 мөрөөр тасарна

`view=direct` хэсэгт 51 борлуулалт үүсгэхэд API-ийн `count=51`, `items.length=50`, DOM-д 50 мөр байв. Дараагийн хуудасны товч, хуудасны state, “цааш үзэх” үйлдэл байхгүй. Нийт дүн бүх бүртгэлийг хамарч байгаа ч жагсаалт бүх мөрийг үзүүлэхгүй.

- Код: [direct-sales-panel.tsx](../app/direct-sales-panel.tsx), жагсаалтын URL ба хүснэгт; [inventory API](../app/api/inventory/route.ts), `page`/`limit` болон sales query.
- [51 бүртгэлтэй харагдац](../artifacts/full-ui-ux-probes-2026-09-21/direct-51-desktop.png).
- Засвар: server pagination-тай `Pagination`, нийт мөр/харагдаж буй хүрээ, шүүлтүүр өөрчлөхөд 1-р хуудас руу буцах.
- Хүлээн авах шалгуур: 51, 101 бүртгэлтэй үед бүх мөрд хүрдэг; ажилтан, хугацаа, хайлттай хослон зөв ажилладаг.

### UX-02 — Улаанбаатарын огноо нэг өдрөөр зөрнө

Туршилтын `sold_at=2026-09-20T18:30:00.000Z` нь УБ цагаар **2026-09-21 02:30**. Шууд борлуулалтын хүснэгт **2026-09-20** гэж харуулсан. Шүүлтүүр УБ өдрийн хязгаар хэрэглэдэг боловч хүснэгт `(sold_at || created_at).slice(0,10)` хэрэглэж байна.

- Код: [direct-sales-panel.tsx](../app/direct-sales-panel.tsx), огнооны `TableCell`.
- [Огнооны зөрүүний зураг](../artifacts/full-ui-ux-probes-2026-09-21/direct-timezone.png).
- Засвар: `Asia/Ulaanbaatar` бүс эсвэл системийн нэгдсэн огноо форматлагч ашиглах.
- Хүлээн авах шалгуур: УБ 00:00 орчмын бүртгэлийн харагдах өдөр, хугацааны шүүлтүүр, тайлан хоорондоо таардаг.

### UX-03 — Checkbox/radio-ийн нэр алга

Системийн тохиргооны 5 radio, Google Sheets-ийн түүх оруулах checkbox, гишүүний “Идэвхтэй” checkbox дээр axe `label` алдаа илрүүлсэн. Харагдах текст байгаа ч Ant компонентын дотоод `label` болон гаднах `label`-ийн бүтэц input-ийн accessible нэрийг хоосон болгож байна. Radio-ийн текст дээр дарахад сонгогдож байгааг тусдаа шалгасан; энд асуудал нь нэршил/хүртээмж юм.

- Код: [choice-input.tsx](../components/ui/choice-input.tsx), [settings-panel.tsx](../app/settings-panel.tsx), [sheets-panel.tsx](../app/sheets-panel.tsx), [crm.tsx](../app/crm.tsx).
- [Системийн тохиргоо](../artifacts/full-ui-ux-audit-2026-09-21/settings-0.png).
- Засвар: Ant Checkbox/Radio-ийн `children` дотор текст оруулах, эсвэл `id`–`htmlFor`/`aria-labelledby`-г нэг утгатай холбох; nested label арилгах.
- Хүлээн авах шалгуур: сонголт тус бүр өөрийн Монгол accessible нэртэй, axe `label` алдаагүй; keyboard болон текст дээр дарах ажиллагаа хэвийн.

### UX-04 — Өнгөний ялгарал

Давтагдсан гол жишээнүүд:

| Элемент | Хэмжсэн харьцаа | Хүлээгдэж буй доод утга |
|---|---:|---:|
| Өнөөдрийн ажил: `.perf-stats` тайлбар | 3.81:1 | 4.5:1 |
| Хүсэлтийн тоон badge | 4.29:1 | 4.5:1 |
| Дахин ажиллах бүлгийн тайлбар | 4.20:1 | 4.5:1 |
| Зааврын тайлбар | 3.86:1 | 4.5:1 |
| Хуваарийн амралтын өдрийн жижиг бичвэр | 4.45:1 | 4.5:1 |

Ердийн хэмжээтэй бичвэрийн шалгуурыг [WCAG contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)-аар харьцуулсан. Үндсэн 70 төлөвийн 30-д энэ rule давтагдсан; эдгээрийг 30 тусдаа дизайн алдаа гэж тоолоогүй.

- Код: [globals.css](../app/globals.css), [schedule.css](../app/schedule.css), өнгөний theme/token.
- Засвар: тайлбарын текстийн өнгийг бараан болгох, badge-ийн дэвсгэртэй хослуулан шалгах; hover/selected төлөвийг давхар шалгах.
- Хүлээн авах шалгуур: хэвийн болон hover төлөвт бага контрасттай бичвэргүй; зөвхөн өнгөөр төлөв ялгахгүй.

### UX-05 — Давхар үндсэн хэсэг

`SidebarInset` нь Ant `Layout.Content` буюу `main` гаргана. Дотор нь CRM дахин `<main className="main-content">` гаргаж байна. Үндсэн шалгалтын 69 төлөв дээр `landmark-main-is-top-level`, `landmark-no-duplicate-main` давтагдсан.

- Код: [sidebar.tsx](../components/ui/sidebar.tsx), `SidebarInset`; [crm.tsx](../app/crm.tsx), workspace layout.
- Засвар: нэг л үндсэн `main` үлдээх; дотор/гаднах нөгөө wrapper-ийг `div` болгох.
- Хүлээн авах шалгуур: үндсэн хуудас нэг `main` landmark-тай, nested main байхгүй.

### UX-06 — Хайлт өөрчлөлт болж тоологдоно

Шинэ хүсэлтийн “Эх сурвалж” сонголт дотор хайлт бичихэд **FormData өмнөхтэйгөө яг ижил** үлдсэн. Гэсэн ч `.draft-hint` гарч, хаахад хадгалаагүй өөрчлөлтийн confirm гарсан. Draft snapshot нь Ant Select-ийн нэргүй дотоод search input-ийг бас тоолдог.

- Код: [draft-guard.tsx](../components/draft-guard.tsx), `snapshot` ба `onChangeCapture`; [form-controls.tsx](../components/ui/form-controls.tsx).
- [Бодит сонголт өөрчлөгдөөгүй үеийн зураг](../artifacts/full-ui-ux-probes-2026-09-21/select-search-draft.png).
- Засвар: бизнес өгөгдлийн талбаруудыг transient search талбараас ялгаж snapshot хийх. Нэргүй боловч бодит утга хадгалдаг controlled талбарыг санамсаргүй алгасахгүй байх.
- Хүлээн авах шалгуур: зөвхөн хайлт бичээд хаахад confirm гарахгүй; бодит сонголт/текст өөрчлөхөд хамгаалалт үргэлжлэн ажилладаг.

### UX-07 — Үр дүнгүй хайлтын ARIA

Select-д тохирохгүй үг хайхад `aria-activedescendant` нь DOM-д байхгүй `..._list_-1` элемент рүү заасан. Мөн хоосон `listbox` дээр `aria-required-children` анхааруулга гарсан. Энэ төлөвийг screen reader-ийн дуут үр дүнгээр нэмэлтээр баталгаажуулах шаардлагатай.

- Код: [form-controls.tsx](../components/ui/form-controls.tsx), Ant Select-ийн no-results төлөв.
- Баримт: [probe evidence](../artifacts/full-ui-ux-probes-2026-09-21/evidence.json), `select-search-draft`.
- Засвар: үр дүнгүй үед active descendant-ийг цэвэрлэх боломж/сангийн засварыг шалгах; “Илэрц олдсонгүй” төлөвийг зөв зарлуулах.
- Хүлээн авах шалгуур: бүх `aria-activedescendant` бодит id руу заадаг; хайлтын хоосон төлөв хүртээмжтэй.

### UX-08 — Mobile дээр үндсэн ажил хэт доор байна

320×844 дэлгэц, шинэ ачаалалтын үед эхний мөрийн Y байрлал: бүх хүсэлт **987px**, агуулахын бараа **1280px**, хүргэлт **1464px**, дахин ажиллах бүлэг **2079px**. Header, summary, давхар цэс, шүүлтүүрүүд үндсэн ажлыг дэлгэцийн доор түлхэж байна. Энэ нь heuristic UX асуудал; дангаараа WCAG зөрчил гэж тооцоогүй.

- [Агуулах mobile](../artifacts/full-ui-ux-audit-2026-09-21/inventory-390.png), [Хүргэлт mobile](../artifacts/full-ui-ux-audit-2026-09-21/delivery-390.png).
- Засвар: mobile summary-г хураангуй/эвхдэг болгох, нэмэлт шүүлтүүрийг “Шүүх” drawer-д оруулах, үндсэн үйлдэл ба хайлтыг эхэнд үлдээх.
- Хүлээн авах шалгуур: түгээмэл жагсаалтад эхний бодит бүртгэлд хүрэх гүйлгэлт мэдэгдэхүйц багасах; идэвхтэй шүүлтүүрийн тоо/утга үргэлж ойлгомжтой байх.

## Хэвийн байсан зүйлс, батлагдаагүй дохио

- 81 screenshot-д баримтжуулсан хуудасны гаднах хэвтээ overflow илрээгүй. Хүснэгтийн дотоод horizontal scroll-ийг page overflow гэж тооцоогүй.
- Эдгээр 81 төлөвт JavaScript runtime exception бүртгэгдээгүй. Энэ нь бүх боломжит үйлдэл алдаагүй гэсэн баталгаа биш.
- Одоогийн build дээр `node scripts/ux-audit.mjs`-ийг дахин ажиллуулахад бүрэн давсан: хадгалаагүй өөрчлөлтийн хамгаалалт, түүхээр буцах/урагшлах, keyboard таб, талбарын шалгалт, хүсэлт сэргээх, SMS хадгалах/устгах, алдаанаас дахин оролдох, mobile чатны ноорог, дэлгэцийн overflow. [Regression нотолгоо](../artifacts/antd-ux-audit/evidence.json).
- Radio-ийн харагдах текст дээр дарахад сонголт ажиллаж байна; UX-03 нь accessible нэрийн асуудал.
- axe-ийн `scrollable-region-focusable` дохиог Chrome дээр гараар няцаасан: Tab-аар тайлангийн scroll хэсэгт хүрч, ArrowRight-аар `scrollLeft: 0 → 40` болсон. Батлагдсан алдааны тоонд оруулаагүй; бусад browser-д нэмж шалгана.
- SMS устгалын нэг regression ажиллуулахад богино хүлээлтийн дараах assertion унасан. Тусдаа, үр дүнг хүлээсэн туршилтаар мөр **2 → 1** болж устгал ажилласан; үүнийг бүтээгдэхүүний батлагдсан алдаа гэж тайлагнаагүй.
- Шууд борлуулалтын маягтын анхны screenshot locator товчны хуучин нэр ашигласан. Зөв “Борлуулалт бүртгэх” товчоор desktop/mobile дээр давтан шалгасан.
- Хэмжээгээр жижиг гэж илэрсэн дотоод Select input, disabled pagination icon-уудыг шууд товчийн WCAG алдаа гэж тоолоогүй. [Target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) нь зай, parent hit area, exception-уудтай тул гаднах бодит товших талбайг тусад нь үнэлэх шаардлагатай.
- [Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)-ийн 320px лавлагаагаар өргөнийг шалгасан ч хоёр хэмжээст хүснэгт болон browser-specific зан төлөвт тусдаа үнэлгээ шаардлагатай.
